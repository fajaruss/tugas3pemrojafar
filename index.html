Tentang Saya

Tentang Saya

Halo nama saya Fajar Arya Pratama. Saya mahasiswa aktif program Studi Sistem Informasi di Fakultas Ilmu Komputer. Saya memiliki ketertarikan pada bidang fotografi, pengembangan web, analis sistem informasi. Saya senang belajar hal baru, karena dapat membuat saya menjadi lebih pintar dan dapat mengemukakan ide-ide yang dapat saya kembangkan di masa depan. Selain itu saya juga tertarik untuk mengembangkan kemampuan dalam pemrograman dan pembuatan sistem yang mudah digunakan. Selama menjadi mahasiswa, saya terus berusaha meningkatkan pengetahuan dan keterampilan melalui tugas dan projek perkuliahan.

Selain itu saya juga memiliki hobi travelling, olahraga dan fotografi. Terutama travelling, karena frekuensi perjalanan saya cukup jauh teman-teman saya terkadang sering bertanya kepada saya tentang rute termurah menuju tujuan tertentu. Selain itu, saya adalah orang yang dapat menemukan ide/solusi ketika ada masalah atau konflik yang sedang berlangsung, skill itu saya dapatkan ketika saya berada di Organisasi MPK saat SMA.

Berikut ialah skill yang saya dapatkan ketika berorganisasi:

  • Fotografi
  • Pengembangan Web
  • Pengembangan Sistem
  • Travelling
  • Olahraga

Halaman web ini dibuat menggunakan HTML, CSS, dan Bootstrap sebagai latihan memahami dasar-dasar pengembangan web. Saya mempelajari fungsi tiap tag dan aturan styling agar dapat digunakan sesuai kebutuhan halaman, dengan harapan bisa membuat halaman web yang lebih kompleks ke depannya.
